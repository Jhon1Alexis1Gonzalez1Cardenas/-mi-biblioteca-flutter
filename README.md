# -mi-biblioteca-flutter

## Reglas de Colaboración

Este repositorio sigue el flujo **GitHub Flow**:

1. La rama `main` siempre contiene código estable y funcional. No se permite hacer push directo a `main`.
2. Cada nueva funcionalidad o corrección se desarrolla en una rama propia creada desde `main`, con el formato `feature/nombre-corto` (por ejemplo, `feature/agregar-libro`, `feature/buscar-por-autor`).
3. Al terminar el trabajo en una rama, se abre un **Pull Request** hacia `main`.
4. Todo Pull Request requiere **al menos una revisión aprobada** antes de poder fusionarse.
5. Una vez aprobado y fusionado el Pull Request, la rama `feature/...` correspondiente se elimina.
